# 다른 도구·다른 PC에서 이어가기

특정 모델, 플러그인, 대화 기록 없이도 이 저장소만으로 작업을 이어갈 수 있게 한다.

## 새 도구에 처음 줄 말

> 이 저장소의 `AGENTS.md`, `docs/continuity/START_HERE.md`, `docs/continuity/STATUS.md`를 읽고 작업을 이어가세요. `git status`로 커밋되지 않은 변경을 먼저 확인하고 보존하세요. 실제로 검증한 것과 검증하지 않은 것을 구분하고, STATUS의 "다음 할 일" 맨 위부터 진행하세요. 단계가 끝나면 STATUS를 갱신하세요.

## 같은 PC에서 도구를 바꿀 때

1. 다른 도구의 파일 쓰기를 먼저 멈춘다.
2. `git status --short`로 진행 중인 변경을 확인한다.
3. STATUS의 "진행 중"과 "다음 할 일"을 읽는다.
4. 마지막 검증 이후 소스가 바뀌었으면 관련 검사를 다시 돌린다.

## 다른 PC에서 이어갈 때

1. 진행 중인 작업은 작업 브랜치에 push한다. 미완성 작업을 운영 브랜치에 push하지 않는다. 운영 브랜치 push는 배포를 시작한다.
2. 새 PC에서 clone하고, 비밀값은 `STATUS.md`의 "설정 위치"에 적힌 곳에서 따로 복원한다.
3. 위 "같은 PC" 순서를 따른다.
